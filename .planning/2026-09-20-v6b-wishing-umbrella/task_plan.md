# 《Wishing Umbrella》v6b e500 翻唱执行计划

## 目标

使用仓库已登记的最新 v6b e500 权重与匹配 index，对用户提供的干声完成独立版本的整曲 RVC 翻唱；保留原始音频、旧模型和旧试听结果，并把技术验收与人工试听分开。

## 成功标准

- 输入、匹配伴奏、v6b 权重和 index 均存在，哈希与清单或预检记录一致。
- 使用 RMVPE、pitch=0、index_rate=0.1、rms_mix_rate=1.0、protect=0.33、7 秒核心+0.5 秒上下文、100 ms overlap-add。
- 整曲核心区连续覆盖，无静默缺尾；输出完成 40 kHz 人声、44.1 kHz 人声和 44.1 kHz 双声道混音的技术合同检查。
- 最终状态保持 `technical_pass / quality_pending`，等待用户试听安静段、弱声、高音、高潮、日语咬字和尾部收束。
