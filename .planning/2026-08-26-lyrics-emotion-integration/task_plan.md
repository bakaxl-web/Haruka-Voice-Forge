# 歌词语义情绪接入 RVC 流程研究

## 目标

研究如何把日语歌词语义情绪分析接入当前 Haruka RVC 歌唱翻唱流程，并给出可执行的最小接入方案。

## 范围

- 纳入：歌词获取、日语文本情绪分析、歌词与音频时间对齐、情绪标签与 RVC 参数的映射、声学情绪融合、验证方式。
- 对照：当前 `run_rvc_aligned.py`、`run_segmented_rvc.py` 及最近的《中庭の少女たち》实验。
- 不修改：现有推理脚本、模型、索引、音频产物和既有规划文件。

## 阶段

| 阶段 | 状态 | 完成判据 |
| --- | --- | --- |
| 1. 盘点当前管线 | 已完成 | 已确认 RVC 入口、参数和分段边界机制 |
| 2. 核查语义模型与对齐方案 | 已完成 | 已明确两种可行模型路线、日语强制对齐路径及其依赖和限制 |
| 3. 设计最小接入架构 | 已完成 | 已明确输入、输出、接口、融合方式和失败回退 |
| 4. 给出实施顺序与验证门槛 | 已完成 | 已明确不改变旧流程的 A/B 实验顺序和质量门槛 |

## 错误与风险记录

| 问题 | 处理 |
| --- | --- |
| 当前没有现成的歌词语义情绪接口 | 先区分外部模型、规则/LLM 标注和声学分析三种层次 |
| 当前目标歌曲没有本地歌词和逐句时间戳 | 实际试验前需要用户提供日语歌词文本；Whisper 只作为草稿或交叉检查，不能作为歌唱对齐的唯一依据 |
| 歌词情绪模型训练域不是歌曲 | 把语义输出当作弱先验；由声学特征决定强度，并保留人工覆盖和 A/B 对照 |
| 分段参数硬切会产生边界跳变 | 只在短句/乐句边界换挡，并保留相邻上下文和交叉淡化 |
