# 研究发现

## 已知背景

- 目标区间为 193–212 秒，位于 `bridge_reflection`，当前 e80/e40 版本都使用同一套低索引、低动态参数。
- 之前的 7 秒块接缝交叉淡化已降低波形跳变，但用户试听后认为问题仍在，说明接缝不是主要听感根因。

## 分离链路证据

- MSST-GUI 的实际日志显示，这首歌依次经过 `MelBandRoformer_kim.ckpt`、`bs_roformer_karaoke_frazer_becruily.ckpt`、`dereverb_mel_band_roformer_mono_anvuew_sdr_20.4029.ckpt` 和 `denoise_mel_band_roformer_aufr33_sdr_27.9959.ckpt`。
- 因此当前 `..._vocals_Vocals_noreverb_dry.wav` 并不是只经过普通人声分离；它已经经过 Karaoke 阶段。不过该 Karaoke 权重的说明是“偏保守”，且不严格保证单一主唱，不能把输出直接称为干净的单主声。
- Karaoke 阶段的 `Vocals` 文件是主声候选，配套的 `instrumental` 文件在这条级联链中不是伴奏，而是该阶段从上游人声中移除的残余候选。GUI 的级联目录和 `inference.py` 的差分逻辑共同支持这一解释。
- 目标区间 193–212 秒内，上游 `vocal_stage - kara_lead` 与 Karaoke 残余轨的相关系数为 1.0，重建误差约为 -180.81 dB；参考区间的相关系数同样为 1.0，误差约为 -183.34 dB。也就是说，`kara_lead + kara_residual` 可以无损重建 Karaoke 阶段的上游人声输入。
- 目标区间残余轨相对上游人声约低 13.23 dB，参考区间约低 13.97 dB；目标比参考多约 0.74 dB 的被移除成分。这支持“目标区间的叠唱/附加声部更容易影响单声部转换”的假设，但不能单独证明残余轨纯粹是和声。
- 分秒级分析显示残余几乎不活跃于 3:13–3:19 和 3:22–3:26，但在约 3:19–3:21、3:26–3:32 达到约 -25 至 -21 dB，而主声候选约为 -16 至 -14 dB；这些区段的残余/主声能量差约为 -10 至 -9 dB，足以影响重建听感。
- 在残余有足够能量的区段，pYIN 的残余基频与主声候选常相差约 2.9–4.0 个半音；在同时高置信帧中，约 86%–100% 的帧落在 2–7 半音差异范围。这是独立叠唱层的支持证据，但仍是自动基频代理，不能替代试听或原始多轨。
- 活跃残余的左右声道相关性约 0.19–0.58，side/mid 能量差约 -6 至 -1.7 dB；主声候选相关性约 0.85–0.92、side/mid 约 -14 至 -11 dB。残余明显更宽、更相位化，既符合叠唱/合唱的空间处理，也可能混有分离伪影。

## 模型能力边界

- 当前本机存在的 Karaoke 权重只有 `bs_roformer_karaoke_frazer_becruily.ckpt` 这一套；配置中描述的更激进 `mel_band_roformer_karaoke_becruily`、`mel_band_roformer_karaoke_aufr33` 和 `kar_gabox` 权重未在本机找到，不能在本次研究中假设它们可用。
- 现有 Karaoke 配置输出的是一个目标 stem 与其余残余，不是“主唱 1 / 主唱 2 / 和声”三个独立 stem。残余候选可能包含和声、漏出的主声、混响/噪声或其他未被模型归类的成分。
- RVC 单次推理对一条输入使用一套 F0。若多个声部在同一输入中有不同基频，把它们先相加再转换会迫使模型用一个基频解释多个声部；要保留叠唱结构，至少需要把可分离的层分别转换或保留部分原始层。

## 已核查的限制

- 残余轨具有活跃区的有声/谐波证据，但也有较高频谱平坦度和强相位化特征，因此只能称为“叠唱/漏声残余候选”，不能称为纯和声。
- `noreverb`/`dry` 是 Karaoke 主声候选分支的后处理结果，不包含被移入 Karaoke 残余的完整层；同时保守 Karaoke 输出内部仍可能留有叠唱。
- 声道和多基频特征足以筛出主声候选与残余候选，但不足以在没有原始多轨的情况下恢复每一个独立主声。
- 风险比较后确定先采用“主声转换、残余保留/衰减”，再决定是否让残余独立 RVC。

## 当前设计方向

- 第一优先候选是“主声候选独立转换 + 残余候选低电平保留”：用 Karaoke `Vocals` 作为 RVC 主输入，避免把明显的多基频直接送进单声部转换；残余先经过低电平、去混响/清理后作为叠层加入。
- 第一优先候选的残余应先保留其原始立体声宽度，且只在能量活跃区段自动门控/淡入；不应直接把整个残余压成单声道后当第二主唱。
- 第二候选是“主声候选和残余候选分别 RVC 转换后混音”。只有在残余轨试听确认确实是有声和声时才采用；否则会把分离伪影也转换成新的机械声。若转换残余，至少应单独取中声道做 RVC，侧声道保留或衰减，避免 RVC 直接解释相位宽声。
- 不建议第一步直接把残余当作第二条“纯和声”或直接做声道拼接；当前证据只证明它是精确残余，不证明其语义身份。

## 当前结论

- 这不是简单的“把当前 RVC 输出再做一次接缝平滑”问题。最小可验证方向是：主声候选独立转换，随后把原始残余作为宽度可控的叠唱层补回；先不改变 e80、索引、pitch、rms 和 protect，也不引入新的情绪分段。
- 当前 dry 输入来自 Karaoke `Vocals` 后续去混响/降噪链，因此 RVC 实际看到的仍可能包含未被保守 Karaoke 模型分开的部分叠唱，同时又完全缺少被移入残余的部分。分层重建要同时处理这两个问题：主声候选减少多基频，残余层恢复结构。

## 推荐重建架构

1. 从同一时间轴准备主声候选 `L` 和宽残余候选 `S`。`L` 使用已有的 Karaoke 主声分支后处理干声；`S` 使用 Karaoke 阶段的残余，不把它误当成歌曲伴奏。
2. 只把 `L` 送入 RVC，得到 Haruka 主声 `L_rvc`。这样 RVC 的单一 F0 假设只作用于主层，不会强迫它解释多个叠唱基频。
3. 对 `S` 做能量跟随的软门控，不做硬切。首版保留 `S` 的原始双声道宽度，并按活跃区的原始层间比例补回；这样 3:19–3:21、3:26–3:32 会恢复重叠密度，3:13–3:19 和 3:22–3:26 不会把分离底噪抬起来。
4. 只有当原始残余混合版确认层次方向正确，才把 `S` 的中声道单独送入 RVC，侧声道作为宽度层保留/衰减。不能直接把宽立体声 `S` 平均后全量转换，也不能把它直接命名为纯和声。
5. 最终混音顺序是伴奏、`L_rvc`、残余层三者对齐后相加，最后统一峰值保护；不得把当前整条复合人声的 RVC 输出再与同一层残余重复叠加。

## 为什么首选原始残余补回

- 当前残余在活跃段已有真实有声/谐波证据，同时左右声道相关性低、side/mid 接近 0 dB，说明它承担了空间化叠唱的听感。
- 但现有权重只输出“目标 stem + 其余残余”，不能证明残余是干净的第二主声。先原样低电平补回，风险低于把分离伪影再次转换成 Haruka 的机械声。
- 若 B 仍不自然，问题可能是保守 Karaoke 主声候选内部仍含多主声；这时需要更激进的 lead/backing 分离权重、原始多轨，或真正的多基频分层，而不是继续调接缝交叉淡化。

## 验收门槛

- 技术：19 秒输入/输出保持原采样率和精确帧数；主声转换为单声道、残余补回保持双声道；无 NaN/Inf、无削波、无时间漂移。
- 听感：分别检查 3:19–3:21 和 3:26–3:32 的重叠层次、主声咬字、和声空间、长音尾部和高音；同时检查 3:13–3:19 的静段是否被残余噪声污染。
- 结论分级：只通过 WAV/帧数是 `technical_pass`；只有试听确认层次更自然且机械感未增加，才进入质量接受。

## 本次执行结果

- A、B、C 均使用 e80 `haruka_singing_v4_cloud_seg12800_e80_s8880.pth`、同一索引、`rmvpe`、`index_rate=0.39`、`rms_mix_rate=0.17`、`protect=0.16`、`pitch=0` 和相同随机种子。
- 3 个输出均为 44.1 kHz、837900 帧、双声道、有限值，峰值约为 0.975–0.980，技术合同通过；三档采用同一总混音增益，便于公平比较。
- B 使用了 35 ms attack、140 ms release 的软门控；C 使用残余中声道独立 RVC，并保留 0.60 倍原始侧声道。两项都是为降低静段噪声和相位化机械感的实验性设置，不代表最终质量结论。

## 用户试听反馈后的补充诊断

- 用户确认问题是“嗓子哑/沙哑”，不是失声。逐句指标显示 A 的主声已经出现该问题：第二句的频谱平坦度约为源干声的 10 倍，3–8 kHz 高频能量占比约为源的 3.6 倍；第三句分别约为 5 倍和 3.9 倍。
- 第三句在加入残余后的 B/C 频谱平坦度比 A 更高，说明叠唱层会放大沙哑感，但不是根因；第二句 B/C 与 A 基本相同，因为残余在该处几乎不活跃。
- 与既有全曲 e80 输出对比，第二、三句也呈现相近的平坦度和高频抬升，故问题不是本次 19 秒裁剪或 A/B/C 混音特有的分块错误。
- 当前更接近“模型/输入组合在这两句产生过亮、非谐波偏多的音色”，而不是单纯 F0 丢失。需先用实际 RMVPE 复核音高跟踪，再决定降低索引、换 e40、改用较少后处理的输入或对这两句局部降调。
- 进一步对比 Vocal、Karaoke 主声、noreverb 和 dry 四个输入版本：dry/noreverb 在第二句的谐波比例约 0.818、3–8 kHz 占比约 0.015，在第三句谐波比例约 0.617、占比约 0.039；它们彼此接近且明显比 A 输出平滑，暂时没有证据表明最后降噪链单独制造了沙哑根因。
- RVC 实际输出的 RMVPE 复核显示其有声帧更连续，但与输入的自动 F0 逐帧匹配不稳定；这更像高密度/高音段的合成谐波和 F0 选择需要继续做对照，不能仅凭自动 F0 把问题归结为失声或单一音高错误。
- e80 `index_rate=0.25` 实际试听候选已生成；自动指标相对 `0.39` 没有改善，第三句频谱平坦度从约 `4.12e-5` 升至 `4.72e-5`，因此不把降低索引作为最终修复。
- e40 `index_rate=0.25` 候选已生成；第三句高频占比略低于 e80，但频谱平坦度约 `7.59e-5`，高于 e80，属于“可能少亮但更粗”的取舍，需用户试听确认。
- 用户试听确认：e40 `index_rate=0.25` 在第二、第三句的实际声线优于 e80，沙哑感更轻；因此后续该区间优先以 e40 为主声基线，e80 保留为对照，不据自动指标否定用户听感。
